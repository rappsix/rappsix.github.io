О себе

Пишу backend на Python и умею довести проект до работающего в интернете продукта: спроектировать данные, подключить платежи, поднять сервер, настроить CI/CD и разобраться, почему в четыре утра отвалился вебхук.

Большой объём в одиночку получается за счёт выстроенного AI-ассистированного процесса: спецификация → план → отдельная ветка → реализация → тесты в CI → автодеплой. ИИ забирает генерацию и рутинный рефакторинг; архитектурные решения, отладку продакшна и разбор инцидентов оставляю за собой. Под каждый проект держу файл правил для ассистента и ставлю технические предохранители — например, git-хук, который не даёт случайно запушить в main.

Есть опыт коммерческой работы на заказ — сайт для сервиса 3D-печати. В команде разработки пока не работал, и иду именно за этим: за код-ревью от сильных инженеров и практикой в большой чужой кодовой базе.

Zapisly

в продакшне приватный репозиторий
SaaS-платформа онлайн-записи · автор и единственный разработчик · май 2026 — сейчас

Мульти-тенантная платформа для записи клиентов на услуги: Telegram-бот, REST API и Telegram Mini App. Развёрнута на VPS, работает в продакшне с реальными пользователями.

  • Backend: FastAPI и aiogram 3 — 39 доменных моделей, 40 сервисов бизнес-логики, около 45 000 строк Python
  • Данные: PostgreSQL через SQLAlchemy 2 async и asyncpg, 84 миграции Alembic, Redis и Celery для фоновых задач и отложенных уведомлений
  • Мульти-тенантность: изолированные данные бизнесов на одной платформе плюс режим собственного бота для клиента на premium-тарифе
  • Платежи: YooKassa и интеграция с ФНС «Мой налог» — автоматические чеки для самозанятых
  • Интеграции: двусторонняя синхронизация с Google Calendar по OAuth 2.0, генерация iCalendar-фидов, QR-коды для офлайн-точек
  • Mini App: React 18 + Vite + Tailwind, 91 компонент — запись клиента и кабинет мастера внутри Telegram
  • Предметная логика: расчёт свободных слотов с учётом смен и отпусков, лист ожидания, лояльность и штамп-карты, промокоды, пакеты визитов, реферальные программы, зарплаты мастеров, финансовый учёт, админ-панель с аудит-логом
  • Качество и деплой: 112 тестовых файлов на pytest, CI поднимает реальные PostgreSQL и Redis на каждый push; деплой — push в main → тесты → доставка на сервер → миграции автоматом. Крон-бэкапы БД с ротацией, Sentry

Задача, которой я горжусь: DPI-блокировки Telegram в России

Бот терял большинство запросов к Telegram. Разобрался и починил: webhook переехал на www-субдомен за Cloudflare-прокси, потому что Telegram надолго кеширует IP апекс-хоста и не подхватывал смену адреса; внутри контейнера закрепил IP api.telegram.org, так как обычный DNS отдавал IPv6 без маршрута; на исходящие запросы добавил ретраи сетевых сбоёв. Бот стал работать стабильно.
